# Mi Proyecto
Este es un proyecto para practicar Git y GitHub.
## Instalación
Clona el repositorio y listo.

## Comandos utilizados

- **git init**: crea un repositorio Git nuevo en la carpeta, agregando la carpeta oculta .git que guarda todo el historial.
- **git add**: mueve los cambios de un archivo al area de staging, dejandolos listos para el proximo commit.
- **git commit**: guarda una version permanente de los cambios que estan en staging, junto con un mensaje descriptivo.
- **git push**: sube los commits guardados localmente al repositorio remoto en GitHub.
- **git status**: muestra en que estado esta cada archivo (sin seguimiento, modificado, en staging o sin cambios).
- **git diff**: muestra linea por linea que cambio en un archivo respecto al ultimo commit.
- **git log**: muestra el historial de commits, con autor, fecha y mensaje.
- **git restore**: descarta cambios sin confirmar, devolviendo el archivo a como estaba en el ultimo commit.
